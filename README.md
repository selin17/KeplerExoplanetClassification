# Kepler Exoplanet Classification

**A Machine Learning Approach to Classifying Kepler Exoplanet Candidates**

## Project Overview

This project focuses on classifying Kepler Objects of Interest (KOIs) into two categories:

- **CONFIRMED:** Objects identified as confirmed exoplanets.
- **FALSE POSITIVE:** Objects that are not confirmed exoplanets.

The project uses multiple machine learning algorithms to investigate the classification problem, compare model performance, handle missing values and class imbalance, and examine the impact of data leakage on evaluation results.

In addition, the trained model is used to estimate planet probabilities for objects originally labeled as CANDIDATE.

## Dataset

The dataset was obtained from the **NASA Exoplanet Archive**, using the Kepler Objects of Interest (KOI) Q1–Q17 DR25 table.

Dataset overview:

| Description | Count |
|---|---:|
| Total records | 8,054 |
| CONFIRMED | 2,731 |
| FALSE POSITIVE | 3,965 |
| CANDIDATE | 1,358 |
| Labeled records used for training and testing | 6,696 |

The CANDIDATE records were kept separate from the labeled training and testing data.

The main classification task uses 37 features:
- 36 numerical features
- 1 categorical feature

## Technologies and Libraries

The project was developed using Python.

Main libraries:

- **Pandas:** Data manipulation and analysis
- **NumPy:** Numerical operations
- **Scikit-learn:** Machine learning models and evaluation
- **Imbalanced-learn:** SMOTE implementation
- **Matplotlib:** Data visualization

## Data Preprocessing

The following preprocessing steps were applied:

1. Removal of identifier columns and irrelevant features.
2. Removal of completely empty columns.
3. Missing value imputation:
   - Median imputation for numerical features.
   - Most frequent value imputation for categorical features.
4. Outlier handling using IQR-based clipping.
5. Yeo-Johnson transformation and standardization for numerical features.
6. One-hot encoding for categorical features.

All preprocessing operations were integrated into machine learning pipelines to prevent information leakage between training and test data.

## Machine Learning Models

Six classification algorithms were implemented and compared:

1. Decision Tree
2. Random Forest
3. Support Vector Machine (SVM with RBF kernel)
4. Multi-Layer Perceptron (MLP)
5. Gaussian Naive Bayes
6. Logistic Regression

Hyperparameter optimization was performed using GridSearchCV with 5-fold Stratified Group Cross-Validation.

The grouping strategy ensures that observations belonging to the same Kepler star are not distributed across different folds.

## Handling Class Imbalance

Three approaches were investigated using Random Forest:

- No balancing
- Class weighting (`class_weight="balanced"`)
- SMOTE (Synthetic Minority Over-sampling Technique)

SMOTE was applied only within the training folds through an imbalanced-learn pipeline.

This prevents synthetic samples from influencing the validation or test data.

## Model Evaluation

Models were evaluated using multiple performance metrics:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
- Specificity
- Matthews Correlation Coefficient (MCC)
- Cohen's Kappa
- Balanced Accuracy

The project also generates ROC curves and confusion matrices for model comparison.

## Data Leakage Analysis

A separate experiment was conducted to investigate how data leakage can affect model performance.

Features generated by Kepler's own vetting process, such as `koi_score`, `koi_pdisposition`, and false-positive flags, were examined.

Different feature sets were compared to demonstrate how including information related to the target classification can artificially increase model performance.

This experiment highlights the importance of selecting appropriate features and designing reliable evaluation procedures.

## Results

The best-performing model based on test ROC-AUC was **SVM (RBF)**.

| Model | Accuracy | F1-Score | ROC-AUC |
|---|---:|---:|---:|
| SVM (RBF) | 0.9365 | 0.9217 | 0.9820 |
| MLP | 0.9350 | 0.9183 | 0.9811 |
| Random Forest | 0.9291 | 0.9106 | 0.9801 |
| Logistic Regression | 0.9022 | 0.8795 | 0.9630 |
| Decision Tree | 0.8887 | 0.8590 | 0.9508 |
| Naive Bayes | 0.8506 | 0.8233 | 0.9301 |

### Additional Experiments

**Class Balancing:**

The SMOTE experiment achieved an F1-score of 0.9132 and ROC-AUC of 0.9782 in grouped cross-validation.

**Data Leakage:**

The leakage experiment showed that including Kepler-generated vetting features increased ROC-AUC to 0.9986, compared with 0.9780 using the main clean feature set.

This demonstrates why leakage control is essential for realistic model evaluation.

### Candidate Predictions

The final SVM model was used to score 1,358 CANDIDATE objects.

- 541 objects received a predicted planet probability of at least 0.5.
- 190 objects received a predicted planet probability of at least 0.9.

These values represent model predictions, not official astronomical confirmations.

## Installation and Usage

### 1. Clone the repository

```bash
git clone https://github.com/selin17/KeplerExoplanetClassification.git
```

### 2. Navigate to the project directory

```bash
cd KeplerExoplanetClassification
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

### 4. Run the project

```bash
python kepler_project.py
```

The script uses the included dataset by default.

All generated figures, evaluation tables, and candidate predictions are saved in the `outputs/` directory.
